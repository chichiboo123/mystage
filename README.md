# 🌟 My Stage — 나만의 무대 만들기

어린이·청소년·선생님을 위한 **3D 무대 디자인 웹앱**입니다.
마인크래프트처럼 블록을 쌓고, 진짜 극장처럼 조명을 달아 누구나 나만의 무대를 상상하고 만들어 볼 수 있어요.

**▶ 바로 사용하기: https://chichiboo123.github.io/mystage/**

![공연 모드](docs/perform-mode.png)

## 🧭 이렇게 사용해요 (3단계)

처음 열면 무대를 고르고, 3단계 안내가 나와요. 왼쪽 도구 탭도 같은 순서예요.

| 단계 | 탭 | 하는 일 |
|---|---|---|
| 1️⃣ 만들기 | 🧱 | 블록을 골라 무대를 클릭! 쌓아서 무대를 만들어요 (반블록·지우개 🧽 포함) |
| 2️⃣ 꾸미기 & 조명 | 🪑 💡 | 배우·소품을 놓고, **조명 세트 버튼 하나**로 멋진 조명을 켜요 |
| 3️⃣ 공연하기 | 🎬 | 큐·음악·💨 스모그를 준비하고 **🌙 공연 모드**를 누르면 극장이 어두워지고 내 조명만 반짝! |

완성한 무대는 **📸 사진**이나 **🎥 영상(WebM)** 으로 남기고, **🚶 일인칭 모드**로 무대 위를 직접 걸어 다녀 볼 수 있어요.

- 놓은 것을 **한 번 더 클릭하면 삭제**돼요. (오른쪽 클릭, Delete 키, 목록의 휴지통도 OK)
- **되돌리기**(Ctrl+Z)는 언제나 든든한 친구!
- 사용법은 상단 **❓** 버튼으로 언제든 다시 볼 수 있어요.

## ✨ 주요 기능

### 🏛️ 무대 형태별 정확한 구조 (극장 이론 기반)
각 무대는 실제 극장 이론의 특징을 그대로 담았어요.

| 무대 | 구조 |
|---|---|
| 🏛️ 프로시니엄 | 프로시니엄 아치, 한쪽 객석, 윙(옆무대), 막, 배튼, 배경막(사이클로라마)을 갖춘 액자형 무대 |
| 📐 돌출 무대 | 무대가 객석 안으로 돌출, 관객이 앞·좌·우 3면에서 관람. 시야를 위해 배경은 낮게 |
| ⭕ 사방 객석 무대 | 관객이 360도로 둘러싼 **정중앙**에 무대가 놓여요. 바닥 모양을 **원(기본)·사각형·마름모** 중에 고를 수 있고, 배경막 없이 천장 조명 그리드 중심 |
| ⬛ 블랙박스 | 완성된 무대가 아니라 **아무것도 없는 검은 빈 공간** + 조명 그리드. 무대와 객석을 처음부터 마음대로 배치하는 가변형 공간 |
| 🌲 숲속 | 지붕 없는 숲속 빈터 무대 — 나무 숲, 바위, 언덕, 반딧불이, 은은한 안개 |
| 🌊 바닷가 | 만국기가 펄럭이는 해변 축제무대 — 모래사장, 밀려오는 파도 거품, 야자수, 파라솔 |
| 🚀 우주 | 원형 금속 착륙패드 무대 — 달 크레이터, 돔 거주구·모듈·안테나 기지, 지구와 토성 |

### 🎵 환경 소리 (BGM)
숲·바다·우주 무대에 들어가면 어울리는 배경 소리가 자동으로 무한 반복 재생돼요. 음량 조절·음소거 가능, 장면을 바꿔도 음악이 끊기지 않고, 다른 환경으로 바꾸면 그 환경의 소리로 전환돼요.

### 🧱 마인크래프트식 블록 빌딩
픽셀 텍스처 블록 22종(나무·커튼·벽돌·유리·발광 LED·무지개 색), 반블록, **지우개 도구**(터치 기기에서도 삭제 가능), 초록/빨강 미리보기 고스트.

### 🪑 소품 & 배우 — 주제별 6묶음, 50여 종
인물(배우·어린이·가수·무용수·왕/여왕·해설자·유령) · 가구 · 악기 · 자연 · 무대장치 · 물건.
**🖼️ 내 이미지**: 그림·사진을 올리면 무대 위 2D 입간판으로 세워져요 (크기·회전 조절).

### 🧍 인물 꾸미기 (확장) — 아코디언 UI
모든 인물(유령 제외)을 자유롭게 꾸밀 수 있어요. 항목이 많아 **몸·머리·얼굴·의상·액세서리·소지품·자세**를 접었다 펴는 아코디언으로 나눠, 모바일에서도 한 화면에 너무 많이 보이지 않아요.
- **색상 14색 팔레트**(흰색·검은색 포함): 머리색·상의·하의·모자/액세서리 색에 공통 적용. 흰색 칩은 테두리로 구분, 선택 칩은 파란 테두리로 표시
- **머리 모양**: 짧은 머리·긴 머리·묶은 머리·동그란 머리·민머리
- **표정 10종**: 기본·미소·크게 웃기·놀람·슬픔·화남·긴장·윙크·노래·눈 감기
- **의상 9종**: 티셔츠·셔츠·재킷·드레스·후드·교복·공연복·왕/여왕·운동복 (성별 제한 없이 누구나)
- **액세서리**: 야구모자·왕관·챙모자·머리띠·리본·비니 / 안경·선글라스
- **소지품·악기**: 마이크·기타·바이올린·키보드·대본
- 성별을 고정하지 않고 모든 인물이 모든 항목을 자유롭게 선택 (실시간 미리보기, 🎲 랜덤 버튼)

### 🤸 인물 자세·움직임
인물을 선택하면 편집 패널의 **자세·움직임**에서 동작을 고를 수 있어요. 정적 **자세**와 반복되는 **움직임**을 구분해요(움직임 칩은 초록 점 표시).
- 서 있기 · 걷기 · 달리기 · 손 흔들기 · 양팔 들기 · 춤추기 · 앉기 · 인사하기 · 노래하기 · 악기 연주
- 움직임은 Three.js 렌더 루프에서 시간값으로 부드럽게 구동(과장되지 않게 진폭 조절)
- 인물마다 서로 다른 자세를 저장하고 **여러 인물이 동시에** 각자 움직여요
- 이동·회전·크기·복제·삭제와 충돌하지 않고, 저장 후 불러와도 유지돼요
- 인물 모델은 머리·몸통·팔·다리 **관절 그룹(rig)** 으로 구성해, 목이 꺾이거나 신체가 분리되지 않도록 했어요

### ✏️ 놓은 것 다시 편집
놓은 블록·배우·소품·이미지·조명을 클릭하면 **편집 패널**이 열려요 — 요소 종류에 맞는 기능만 보여줘요.
- 이동(옮길 곳 클릭) · **회전(자유 회전 + 45°마다 자석처럼 딱 맞는 스냅)** · 크기 · 복제 · 삭제
- 블록은 다른 블록으로 색(종류) 바꾸기, 인물은 다시 꾸미기·자세 바꾸기, 조명은 색·밝기·각도·겨누기
- **계단·기둥 등 여러 조각으로 된 소품도 일반 소품과 똑같이** 어느 부분을 클릭해도 통째로 선택돼요 (이동·회전·크기·복제·삭제, 다시 클릭/오른쪽 클릭/Delete 삭제 동일)
- **여러 개 한 번에**: 보기 탭의 '여러 개 선택 모드'를 켜고 무대를 **드래그**하면 소품·이미지·조명은 물론 **블록(이동식 플랫폼 등)**까지 한 번에 골라 함께 이동·회전·복제·삭제
- **객석도 이동**: 객석을 클릭하면 통째로 옮기거나 돌릴 수 있어요 (원위치 되돌리기 포함)
- 모든 변경은 **되돌리기(Ctrl+Z)** 지원

### 📏 간격 눈금 (야광 스파이크 테이프)
화면 옵션의 **간격 눈금**을 켜면 센터(분홍 ＋)부터 좌우로 같은 간격의 야광 테이프와 번호가 표시돼요. **무대 센터 지정** 버튼을 누르고 무대를 클릭하면 원하는 지점을 센터(0)로 삼아 눈금을 다시 그려요(‘↺ 자동’으로 기본 중앙으로 되돌리기). 어떤 무대 모양에서도 센터를 유동적으로 맞출 수 있어요.

### 📋 요소 목록 (사이드바 + 플로팅)
'보기' 탭의 목록 외에도 상단 **목록** 버튼으로 화면 오른쪽에 플로팅 패널을 띄울 수 있어요 (열기/접기/닫기). 목록에서 선택·이름 바꾸기·숨기기·복제·삭제가 가능하고 3D 화면의 선택과 연동돼요.

### 💡 조명 — 초보자도 버튼 하나로
- **조명 세트 16종 (토글)**: 매캔들리스, 독백 스포트, 노을, 콘서트, 디스코, 무지개… 한 번 누르면 켜지고, 같은 버튼을 다시 누르면 꺼져요. 다른 세트를 누르면 교체되고, 직접 단 조명은 그대로 유지돼요
- **직접 달기**: 스포트라이트·팔로우 스팟·워시·플로어·무빙 라이트 5종 — 실제 광원과 그림자, 빛줄기 표현
- 컬러 젤 8색 + 자유 색, 밝기·빔 각도 조절, 하우스 라이트 디머 — **가장 밝게 하면 극장 전체가 완전히 불 켜진 것처럼 환하게** 밝아져요

### 🎬 공연 만들기
- **장면(場)**: 장면마다 블록·조명·소품을 따로 꾸미고 탭으로 전환
- **조명 큐**: 지금 조명을 큐로 저장 → 클릭 한 번에 부드러운 페이드 전환, 순서대로 자동 재생
- **음악**: 오디오 파일 업로드 또는 유튜브 링크(공식 임베드 플레이어)
- **🌙 공연 모드**: 하우스 라이트를 끄고 내 조명만으로 무대 감상

### 💨 스모그 머신 — 뿌연 안개 효과
진짜 공연장처럼 **안개(헤이즈)** 를 뿜어 조명 빛줄기를 살려요.
- **꾸미기 → 무대장치 → 💨 스모그 머신**을 무대에 놓으면 **바로 안개가 켜지고**, 기계의 **노즐이 바라보는 방향**으로 연기가 뿜어져 나와요 (소품이라 이동·회전·복제·삭제 모두 가능)
- 놓은 **기계를 클릭하면 편집 패널에서 바로** 안개 켜기 / 농도 / 한 번에 뿜기를 조절할 수 있어요. **공연 탭 → 스모그 머신** 카드에도 같은 조절이 있고 두 곳이 항상 같은 값으로 연동돼요
- 연기는 무대 앞쪽(객석 방향)으로 **천천히 흘러 무대 전체에 은은하게 깔리고**, 농도를 높이면 **객석까지** 넘어와요
- 여러 대를 놓으면 각자 안개를 뿜고, 연기는 천천히 퍼지며 바닥에 깔리듯 사라져요. 공연 모드에서는 조금 더 진하게 보여요
- 켜짐 상태와 농도는 작품에 함께 저장돼요

### 🎥 영상 촬영 (WebM)
사진뿐 아니라 **움직이는 무대를 영상으로** 남길 수 있어요. (저장·공유 메뉴 → 🎥 영상 촬영)
- **3·2·1 카운트다운** 후 녹화가 시작되고, **화면에 보이는 그대로** 담겨요
- 녹화 중에는 **⏸️ 일시정지 / 🔴 다시 녹화 / ⏹️ 정지** 버튼과 녹화 시간이 표시돼요
- 정지하면 바로 저장되지 않고 **미리보기 창**이 떠요 — 확인한 뒤 **다운로드**하거나 **다시 촬영**할 수 있어요
- 올린 음악·환경 소리도 함께 담겨요(지원 브라우저). 유튜브 음악은 담기지 않아요
- 브라우저 표준 기능(MediaRecorder)만 사용하고, 크롬·엣지에서 가장 잘 동작해요

### 🚶 일인칭 모드 — 무대 위를 걸어 다니기
**보기 탭 → 일인칭으로 걸어보기**를 누르면 무대 한가운데에 사람이 생기고, 그 사람의 **눈높이**에서 무대를 둘러봐요.
- **방향키(또는 WASD)** 이동 · **스페이스바** 점프 · **Shift** 달리기 · 화면을 **끌면** 고개 돌리기 · **ESC** 나가기
- 📱 휴대폰·태블릿에서는 **이동 조이스틱**과 **점프 버튼**이 화면에 나타나요
- 블록을 밟고 올라서고(낮은 턱·반블록은 자동으로 성큼), 무대 끝에서 걸어 내려오면 바닥으로 떨어져요. 벽은 통과하지 못해요
- 배우처럼 **객석을 바라보며** 시작해요 — 내가 만든 무대가 관객에게 어떻게 보이는지 눈높이에서 확인할 수 있어요
- 들어가면 화면 안에 **조작법 안내**가 잠깐 떴다가 사라져요. 눈높이에서도 극장 안이 어둡게 묻히지 않도록 벽·천장 밝기를 자동으로 보정해요

### 📍 무대 방향과 9구역 — 배우 기준으로 정확하게
- 무대의 왼쪽/오른쪽은 **객석을 바라보는 배우 기준**으로 통일: 무대 오른쪽(SR)·무대 왼쪽(SL)
- 9구역 오버레이: 윗무대(US)/아랫무대(DS) × 오른쪽/중앙/왼쪽 = USR·USC·USL / SR·CS·SL / DSR·DSC·DSL — 관객 시점 화면에서 SR 구역이 왼쪽에 보여요
- 사방 객석·블랙박스처럼 정면이 없는 공간은 앱의 **기준 정면**을 오버레이에 함께 안내
- 상수/하수는 전통 현장 용어로 배움터에서 소개 (SR=하수, SL=상수)

- 프로시니엄·돌출·사방 객석·블랙박스의 차이 (블랙박스 = 가변형 공연 공간!)
- Stage Right/Left(배우 기준)와 House Right/Left(관객 기준)
- 업스테이지/다운스테이지가 경사 무대에서 유래한 이야기
- 조명 이론(가산혼합·매캔들리스·큐), 용어 사전, 교실 활동 미션 카드

### 🔒 화면 고정 · 🔍 확대·축소 · 🎯 화면 맞추기
- **화면 고정**(보기 → 화면 옵션): 켜면 화면 **회전·이동·확대**가 모두 잠겨요. 아이들이 무대를 만들다 실수로 화면을 돌리지 않게 도와줘요. 고정 중에는 자물쇠 알약과 안내 문구가 뜨고, 모바일·태블릿에서도 똑같이 동작해요. 고정 상태는 저장돼요
- **확대/축소 버튼**과 **🎯 화면 맞추기(기본 시점 복귀)** 버튼을 3D 화면 오른쪽 아래에 작은 플로팅 버튼으로 배치 — 마우스 휠·두 손가락 핀치와 함께 사용할 수 있고, 확대·축소는 부드럽게 전환되며 너무 가깝거나 멀어지지 않도록 최소·최대 거리를 제한했어요

### 🔄 무대 종류 바꾸기
무대 종류를 바꾸면 **기본 무대 바닥만 새 무대 모양으로 교체**되고, 여러분이 직접 놓은 소품·조명·이미지·블록은 그대로 남아요. 예를 들어 원형 무대에서 프로시니엄으로 바꾸면 바닥은 프로시니엄 기본 무대가 되고, 올려둔 배우와 쌓은 블록은 그 자리에 유지돼요.

### 💾 저장과 공유
브라우저 자동 저장 + 이어서 만들기, JSON 내보내기/불러오기, 📸 스크린샷, **🎥 영상 촬영(WebM)**, **🔗 링크로 공유** — 상단 **저장·공유** 메뉴에 모여 있어요.

- **🔗 링크로 공유**: 서버 없이도 작품을 링크 하나로 나눌 수 있어요. 작품 데이터를 **압축(deflate) 후 URL-safe 인코딩**해 주소 뒤(`#p=…`)에 담아 **최대한 짧은 링크**로 만들고 클립보드에 복사해요. 링크를 열면 시작 화면을 건너뛰고 그 작품이 바로 열려요. (사진을 많이 넣으면 링크가 길어질 수 있어, 그럴 땐 파일 내보내기를 추천해요.)

저장 데이터는 **버전 3(`v:3`)** 이에요. 인물 **자세·움직임**, 확장된 **꾸미기(의상·색상·표정·액세서리·소지품)**, **화면 고정**, **스모그 켜짐·농도**가 함께 저장돼요(스모그 머신 자체는 소품이라 원래 저장돼요). 예전 **`v:2` 파일도 그대로 불러올 수 있고**(자동 마이그레이션), 값이 없는 항목은 안전한 기본값(자세=서 있기, 화면 고정=꺼짐, 안개=꺼짐/보통 농도)으로 채워져 인물·소품이 사라지지 않아요.

## 🚀 직접 실행하기

정적 웹앱이라 서버만 있으면 됩니다. (ES 모듈을 사용하므로 파일을 직접 열지 말고 로컬 서버로 실행하세요.)

```bash
python3 -m http.server 8000   # 또는: npx serve .
```

기본 브랜치에 푸시하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
폰트와 Three.js가 모두 저장소에 포함되어 있어 **인터넷 없이(오프라인)도 동작**합니다. (유튜브 음악 재생만 인터넷 필요)

## 🗂️ 파일 구조

기능이 늘어나며 `main.js`가 지나치게 커지지 않도록 안전하게 분리할 수 있는 부분을 모듈로 나눴어요.

| 파일 | 역할 |
|---|---|
| `js/main.js` | 앱 진입점 — 씬·상호작용·UI·저장/불러오기·조명·장면 |
| `js/blocks.js` | 픽셀 텍스처 블록 정의 |
| `js/props.js` | **순수 소품·인물 3D 모델 생성** (인물 골격 rig 포함) |
| `js/character-customizer.js` | 인물 꾸미기 — 색상·의상·표정·액세서리 데이터와 아코디언 UI |
| `js/character-animation.js` | 인물 자세·움직임 (rig을 시간값으로 구동) |
| `js/camera-controls.js` | 화면 고정·확대/축소·화면 맞추기(OrbitControls 래퍼) |
| `js/smoke-machine.js` | 스모그 머신 안개 파티클 |
| `js/recorder.js` | 영상 촬영(카운트다운·일시정지·미리보기용 WebM 생성) |
| `js/first-person.js` | 일인칭 모드(걷기·점프·블록 충돌·시선) |
| `js/model-validation.js` | (개발용) 소품 형태·바운딩 박스 점검 |
| `js/lighting-presets.js` · `js/education.js` | 조명 세트 · 배움터 자료 |

> 개발용 소품 점검은 브라우저 콘솔에서 `window.__validateProps()` 또는 URL 뒤에 `?validate` 를 붙여 실행할 수 있고, 운영 화면에는 영향을 주지 않아요.
